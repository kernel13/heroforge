## Decisions / deviations worth remembering

- **`slowapi` replaced by `limits`** (slowapi's own engine) in `src/heroforge/rate_limit.py`.
  Reason: slowapi applies limits by decorating an endpoint function, which cannot reach the
  register/login/verify/reset endpoints generated by `fastapi-users` — and the spec *requires*
  limits there. Same windows and storage, attachable as a FastAPI dependency.
- **`skills.sheet_rows` column added** beyond the spec's table. The spec requires creating rows
  "to match the paper sheet's repeat count" (Craft 3, Knowledge 5, Perform 3, Profession 2);
  that count had to live somewhere and reference data is where it belongs.
- `render_item` hook in `migrations/env.py` renders `fastapi-users`' generic GUID /
  TIMESTAMPAware as concrete Postgres types — autogenerate names them without importing them.
- Rules tests use `packages/heroforge-rules/tests/srd.py` (no `__init__.py`) so the two `tests`
  directories do not collide on import.
- pytest-asyncio loop scope is **session** for both fixtures and tests; the engine and container
  are session-scoped and a per-test loop cannot hold their pool.
- Test emails must not use `.test` — `email-validator` rejects reserved TLDs. Use `example.com`.

## Gotchas pinned by tests

- `flat_footed_ac = armor_class - max(effective_dex_bonus, 0)`.
- cross-class `max_ranks = (level + 3) / 2` stays a half-integer; compared against *unfloored* ranks.
- ACP stored non-positive; engine ADDS it; Swim adds twice.
- `grapple_size_modifier` is a stored column, never derived from `size`.
- Load category boundaries inclusive at the top.
- Engine never raises; violations become `DerivedSheet.warnings`.
- `ranks` serialises as a decimal string; "0" and "0.0" are the same value.
