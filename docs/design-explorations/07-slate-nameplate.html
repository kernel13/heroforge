What this exploration is claiming

Axis
Material. The sheet already tells derived from typed by place — slate rail beside parchment column — and the first screen anyone sees teaches none of it. This tile is both materials.
Signature
The class ledger. One row per class, its level right-aligned in a --fig-wide column that is the same column the gold total sits in up in the slate — so the 4 and the 3 line up directly under the 7. The tile shows its own arithmetic, on the one screen that deliberately never calls /api/derive.
Fixes
"druide 4 / mage 2 / Arcane Hiérophante 1" is one string that wraps into soup at any card width. Three rows never wrap, and each class is readable on its own.
Delete
Demoted, not hidden and not confirmed. Today it is an outline button — a frame, a fill and a border at the same weight as the thing you came for. Here it is quiet text at the end of the foot that colours only on hover and focus. F's two-step confirm is separable and can sit on top.
Empty state
The ledger becomes the invitation: "No class yet — open the sheet and add one, the level works itself out from there." A tile with nothing in it should say what to do next, not leave a gap where a list would be.
Costs
The --rail-* tokens reach a component outside DerivedRail for the first time — a real decision, since the rail's material currently means "the engine worked this out", and the level is the only figure here that qualifies. Two dictionary keys, one --fig measurement shared by two elements, no API change, no new font, no new icon.
Risks
Height varies with class count, so a row of tiles is ragged unless the grid stretches them — kept here by li{display:flex} plus margin-top:auto on the foot. And a character with six classes is a tall tile; a cap with "+2 more" would be the obvious next question.
Kept
Name and race remain one control carrying characters.open; the portrait remains an upload control whose writes never touch version; every field shown is one CharacterSummary already sends.
