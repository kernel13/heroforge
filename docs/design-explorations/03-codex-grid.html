Exploration C — Codex Grid. The two page tabs are gone: one continuous document, a contents column instead of pagination, and as many panel columns as the window affords. The forty-row skills table runs in two columns, so the whole list is one screen rather than one scroll. The derived/entered distinction is typographic — an entered value is framed and set in the reading face, a derived value has no frame and is set in the machine face. Two channels before colour is used at all, and an absent derived value leaves an empty space rather than an empty coloured box. This is the risky one: dropping the tabs puts roughly two hundred controls in the accessibility tree at once, which is precisely what unmounting the inactive page avoids today.

What it costs. The most work of the four. `Tabs` comes out and a scroll-spy contents column goes in; every component test that relies on the inactive page being unmounted has to scope its queries to a section instead, because `getByLabelText` over two hundred coexisting controls is no longer unambiguous. The two-column skills table needs the column break computed over sorted display positions while every write stays on the stored index — the existing separation makes that possible, but it is the place to get it wrong. What it buys: no page flipping, the whole skill list at once, and a layout that uses a wide monitor instead of a 1120px column down the middle of it.
