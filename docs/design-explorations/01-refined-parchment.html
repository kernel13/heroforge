Exploration A — Refined Parchment. Same structure as today (panel stack, two page tabs, parchment on leather). What changes: the header collapses to one line, the identity panel gets a hierarchy, panels that report are marked apart from panels where you work, and — the signature — a derived value is ink stamped on the page, an entered value is a ruled blank. Adopting this is a CSS-and-markup change; no data flow moves.

What it costs. Nothing structural. The panel components, the tabs, the two-page split and the draft state all stay. The work is styles.css tokens, a Derived that renders a stamp instead of a tinted tile, a BannerPanel replaced by an ordinary panel with a display-size name field, and a Panel variant for reporting sections. What it does not answer: whether the derived combat numbers should still scroll off the top while you work in the skills table.
