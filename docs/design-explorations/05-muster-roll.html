What this exploration is claiming

Axis
A character list is a register, not a gallery. Optimise for scanning fifteen, not for displaying two.
Signature
The tinted level gutter running the height of the sheet. One figure per line, tabular, centred — the only column on the page you can read without reading any words.
Delete
Demoted into a ⋯ menu at the row end, revealed on hover and on :focus-within, but present in the tab order at all times. Today it is the loudest control on a card whose real purpose is to be opened.
Free win
updated_at is already on CharacterSummary and the card throws it away. "Edited 3 days ago" via Intl.RelativeTimeFormat is locale-aware without a French string of its own.
Empty states
An em dash in the level gutter and a muted "Nothing filled in" — a blank cell in a register reads as a missing value, which is exactly what it is, whereas a blank area on a card reads as a broken card.
Costs
A DropdownMenu primitive (shadcn, already available); two dictionary keys in en.ts and fr.ts; the grid track duplicated between header and row. No API change, no new font, no new icon, no /api/derive call.
Kept
Name and class line remain one control carrying characters.open; the portrait remains an upload control whose writes never touch version; text outside the sheet stays on --on-ground.
Risk
A register with two rows in it looks thin where a two-card grid at least looked deliberate. Worth testing against a brand-new account.
