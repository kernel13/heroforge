FONT CREDITS
============

Two display faces are bundled into this application and served from its own origin. They letter
the section headings and the SRD mark in the header; everything else on the sheet is set in the
reader's own system sans, which is not bundled and needs no licence.

The font files come from the `@fontsource/cinzel` and `@fontsource/medievalsharp` packages, which
redistribute the same woff2 and woff files Google Fonts serves. They are copied into this
application's own asset bundle at build time and are requested from this deployment's origin and
no other: a self-hosted installation whose CORS is restricted to itself would otherwise put a
request to fonts.gstatic.com on every page load, and would letter its headings in a fallback face
on a network with no route off site. This is the same reasoning that bundles the icons rather than
fetching them; see ICONS.txt.

Neither font has been modified. The OFL permits modification, but requires that a modified copy
not be distributed under the original Reserved Font Name.

This file is separate from OGL.txt and ICONS.txt. The SIL Open Font License, the Open Game
License, and CC BY 3.0 cover three different bodies of material, and none of them covers either of
the others.
